# Blog API
A REST API for a blogging platform — user accounts, posts, likes and comments.
Built with FastAPI, PostgreSQL and Docker.

## Live demo

**https://blog-api-1-4i64.onrender.com/docs**
> Hosted on free tiers (Render + Neon)
> so the first request may take up a minute to wake up


## About

A **REST API for a blogging platform**. Users can register, authenticate with JWT,
write and edit their own posts, and like or comment on others'. Includes an
admin role(with very simple functions)

I Built it as a self-taught project to work through a full backend stack end to end —
async database access, schema migrations, containerization, and deployment.

## How to use it

Firstly, account is needed to be created, because most functions of this program
will not work without authentication >

1. Find the **auth** endpoint
2. On **/auth/create** tap on "Try ir out!"
3. In the quotes enter your username, email...
4. Tap "Execute"

**Now your account was created!**

After all, you can authorize on the button "Authorize" above and try this program out!
